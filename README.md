### Репозиторий для освоения MicroPython

## Железо
- ESP8266 NodeMCU
- PyBoard v1.1

## Подключение железа

### Определение устройства в системе
1. **Проверка подключения через `lsusb`**  
   Вывод для **ESP8266 NodeMCU** (чип CP210x):
   ```bash
   Bus 001 Device 002: ID 10c4:ea60 Silicon Labs CP210x UART Bridge
   ```

   Вывод для **PyBoard v1.1** (встроенный USB‑контроллер, CDC ACM):
   ```bash
   Bus 001 Device 002: ID f055:9800 MicroPython Pyboard Virtual Comm Port in FS Mode
   ```

2. **Просмотр устройства**  
   Общая команда для поиска последовательных портов:
   ```bash
   ls -l /dev/ttyUSB* /dev/ttyACM* 2>/dev/null
   ```
   Пример вывода для ESP8266:
   ```bash
   crw-rw---- 1 root dialout 188, 0 Jul 29 20:19 /dev/ttyUSB0
   ```

   Для PyBoard также можно использовать символическую ссылку:
   ```bash
   ls -l /dev/serial/by-id/
   ```
   Пример:
   ```bash
   usb-MicroPython_Pyboard_Virtual_Comm_Port_in_FS_Mode_206C36745853-if01 -> ../../ttyACM0
   ```

3. **Права доступа**  
   Если недостаточно прав или вы не входите в группу `dialout`, добавьте своего пользователя в эту группу:
   ```bash
   sudo usermod -a -G dialout $USER
   ```
   После этого потребуется перелогиниться.

### Особенности работы с платами
- **PyBoard** в Ubuntu определяется как съёмный диск с двумя скриптами: `boot.py` и `main.py`.  
  При подаче питания сначала выполняется `boot.py`, затем `main.py`.  
  При автоматическом запуске платы глобальная переменная `__name__` равна `"__main__"`.

## REPL (интерактивная среда)

### Подключение к интерпретатору
- Для **ESP8266 NodeMCU** используйте:
  ```bash
  screen /dev/ttyUSB0
  ```
- Для **PyBoard v1.1** используйте:
  ```bash
  screen /dev/ttyACM0
  ```

После подключения вы попадёте в интерпретатор Python (приглашение `>>>`).

### Особенности `__name__` в REPL
При импорте модуля из REPL значение `__name__` будет равно имени модуля (например, `"main"`), а не `"__main__"`.
